# 🌱 Ecowell Foundation - NGO Website

A responsive and user-friendly website developed for **Ecowell Foundation**, an NGO focused on environmental conservation, community awareness, social development, and sustainable initiatives.

The website provides information about the organization, its projects, events, activities, gallery, and ways to connect with the foundation.

---

## 📌 About the Project

The **Ecowell Foundation NGO Website** is a static frontend website designed to create a professional online presence for an NGO.

The website focuses on:

- 🌱 Environmental conservation
- 🌍 Sustainable development
- 🤝 Community participation
- 📢 Environmental awareness
- 📋 Social initiatives
- 🌿 NGO projects and activities

The website is designed with a clean interface and responsive layout so that it can be accessed on desktops, tablets, and mobile devices.

---

## ✨ Features

- 🏠 Home page with attractive landing section
- 👥 About Us page
- 🌱 Environmental initiatives
- 📋 Projects section
- 📅 Events section
- 🖼️ Image gallery
- ❓ Frequently Asked Questions (FAQ)
- 📞 Contact page
- 📄 Individual project details
- 📱 Responsive design
- 🎨 Clean and modern user interface
- 🌐 Multiple interconnected pages
